usage: event_study_stablecoins.py [-h] [--days DAYS] [--ticker TICKER]
                                  [--n-placebos N_PLACEBOS] [--seed SEED]
                                  [--alpha ALPHA] [--use-cache-only]
                                  [--output-json OUTPUT_JSON]
                                  [--z-threshold Z_THRESHOLD]
                                  [--lookback LOOKBACK]
                                  [--direction {high,low,abs}]
                                  [--cache-path CACHE_PATH]

Event study: DefiLlama stablecoin 7d supply expansion z-score vs forward
BTC/ETH returns (read-only).

options:
  -h, --help            show this help message and exit
  --days DAYS           Look-back window in days (default 180).
  --ticker TICKER       Crypto ticker for Kraken public OHLC (default 'BTC').
  --n-placebos N_PLACEBOS
                        Placebo bootstrap replicates (default 200).
  --seed SEED           Master seed for placebo bootstrap (default 20260519).
  --alpha ALPHA         Target FDR for Benjamini-Hochberg (default 0.05).
  --use-cache-only      Do not perform live HTTP for signal feeds (cache must
                        cover the window).
  --output-json OUTPUT_JSON
                        Optional path to write the full JSON report.
  --z-threshold Z_THRESHOLD
                        Minimum z-score for supply expansion events (default
                        1.5).
  --lookback LOOKBACK   Rolling z-score window in days (default 180).
  --direction {high,low,abs}
                        Event tail: high=expansion, low=contraction (default
                        high).
  --cache-path CACHE_PATH
                        DefiLlama JSON cache path.
