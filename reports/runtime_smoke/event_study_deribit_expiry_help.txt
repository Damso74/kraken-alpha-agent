usage: event_study_deribit_expiry.py [-h] [--days DAYS] [--ticker TICKER]
                                     [--n-placebos N_PLACEBOS] [--seed SEED]
                                     [--alpha ALPHA] [--use-cache-only]
                                     [--output-json OUTPUT_JSON]

Event study: third-Friday monthly options expiry (calendar) vs forward crypto
return/vol (read-only).

options:
  -h, --help            show this help message and exit
  --days DAYS           Look-back window in days (default 180).
  --ticker TICKER       Crypto ticker for Kraken public OHLC (default 'BTC').
  --n-placebos N_PLACEBOS
                        Placebo bootstrap replicates (default 200).
  --seed SEED           Master seed for placebo bootstrap (default 20260519).
  --alpha ALPHA         Target FDR for Benjamini-Hochberg (default 0.05).
  --use-cache-only      Do not perform live HTTP for signal feeds (cache must
                        cover the window).
  --output-json OUTPUT_JSON
                        Optional path to write the full JSON report.
